## 1 概述

### 1.1 基本信息

| 项目 | 取值 |
| --- | --- |
| 服务地址 | `http://127.0.0.1:8017` |
| 接口前缀 | `/api` |
| 协议与编码 | HTTP/1.1，JSON（`Content-Type: application/json; charset=utf-8`），文件流为 `text/csv` 或 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| 在线文档 | `/api/docs`（交互式）、`/api/openapi.json`（OpenAPI 3.1） |
| 认证方式 | 登录获取 JWT，放在请求头 `Authorization: Bearer <token>` |
| 开放 API | 前缀 `/api/open/v1`，支持 JWT 或 `X-Api-Key` 两种凭证 |
| 时间格式 | 日期 `YYYY-MM-DD`，时间 `YYYY-MM-DDTHH:MM:SS`，时间戳为 Unix 秒 |
| 数值口径 | 价格与金额单位元/公斤，保留 2 位小数；百分比字段为百分数数值（4.22 表示 4.22%） |

### 1.2 统一响应结构

所有接口（文件下载除外）返回统一 JSON 信封：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int / string | 成功固定为 `0`；失败为错误码字符串，如 `E4001` |
| `message` | string | 成功为 `ok`，失败为中文可读提示 |
| `data` | any | 业务数据；失败时为 `null` |

分页接口的 `data` 统一为：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `list` | array | 当前页数据 |
| `total` | int | 满足条件的总条数 |
| `page` | int | 当前页码，从 1 开始 |
| `page_size` | int | 每页条数，默认 20，上限 200 |

失败响应同时使用 HTTP 状态码表达语义，例如参数校验失败返回 HTTP 400、未登录返回 401、权限不足返回 403、资源不存在返回 404、唯一约束冲突返回 409、限流返回 429、服务异常返回 500；响应体仍为统一信封，便于前端统一拦截。

### 1.3 错误码表

| 错误码 | HTTP 状态 | 含义 | 典型场景 |
| --- | --- | --- | --- |
| `E4001` | 400 | 参数校验失败 | 缺失必填参数、日期格式错误、枚举值非法、文件表头不符 |
| `E4002` | 400 | 业务规则不满足 | 状态流转非法、导入数据与主数据不匹配 |
| `E4010` | 401 | 未登录或凭证失效 | 缺少令牌、令牌过期、令牌签名错误、账号被禁用 |
| `E4030` | 403 | 权限不足 | 当前角色缺少所需权限点 |
| `E4040` | 404 | 资源不存在 | 模型、预警、报告、用户、品种、地区等编号不存在 |
| `E4090` | 409 | 唯一约束冲突 | 用户名、编码、任务键、调用方名称重复 |
| `E4290` | 429 | 请求过于频繁 | 开放 API 调用超出调用方限流阈值 |
| `E5000` | 500 | 服务内部异常 | 未捕获异常、数据库连接失败 |

### 1.4 分页与筛选约定

- 分页参数统一为 `page`（默认 1）与 `page_size`（默认 20，1～200）。
- 时间范围参数统一为 `start`、`end`，按闭区间过滤，格式 `YYYY-MM-DD`。
- 排序默认按时间倒序、主键倒序；需要升序时由接口单独说明。
- 数值筛选参数（品种、地区）使用整型主键 `variety_id`、`region_id`；编码类参数（角色键、任务键）使用字符串键。

## 2 认证与令牌

### 2.1 认证流程

1. 调用 `POST /api/auth/login` 提交用户名与密码，获取 `token`、`expires_in`、`user` 与 `permissions`。
2. 后续请求在请求头携带 `Authorization: Bearer <token>`。
3. 令牌为 HS256 签名的 JWT，载荷包含用户编号、用户名、角色键、签发时间与过期时间，默认有效期 720 分钟。
4. 令牌过期或格式错误统一返回 401 与 `E4010`，前端跳转登录页。
5. 调用 `POST /api/auth/logout` 后令牌进入注销名单，再次使用返回 401。

### 2.2 认证相关端点

## 6 开放 API 接入

### 6.1 鉴权

- 调用方由管理员在「后台管理 → 开放 API」创建，系统生成 `client_key` 与 `secret`，密钥仅在创建或轮换时返回一次。
- 请求头使用 `X-Api-Key: <client_key>`；也可直接使用登录 JWT，两种凭证等价，权限按所属角色校验。
- 凭证失效返回 401 与 `E4010`；调用方被禁用或密钥错误同样返回 401。

### 6.2 限流与统计

- 每个调用方配置独立的每分钟请求上限（`rate_limit`），超限返回 429 与 `E4290`，响应头给出 `Retry-After`。
- 每次调用写入调用流水，记录路径、方法、状态码、耗时与时间；流水保留 7 天，可按调用方查询当日、近 7 日调用量与平均耗时。
- 开放 API 与内部接口共用统一响应信封与错误码表。

### 6.3 版本策略

- 开放 API 路径带版本前缀 `/api/open/v1`，新增字段保持向后兼容，不删除既有字段。
- 不兼容变更时新增 `/api/open/v2` 并保留 v1 至少一个版本周期，于本文件「变更记录」登记。

### 7.1 与 M1 冻结版的差异说明

5. 新增 `/api/models/{model_id}` 详情与 `/api/reports/template` 模板下载。
6. 统一响应失败分支的 `code` 为字符串错误码，成功分支为整数 `0`；分页字段固定为 `list/total/page/page_size`。
