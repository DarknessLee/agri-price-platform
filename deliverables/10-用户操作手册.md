## 1. 文档目的与适用范围

本手册面向零基础操作者，按“打开页面—找到按钮—完成操作—核对结果”的顺序说明系统各项功能。读者无需了解技术实现，只需按章节步骤操作即可完成日常价格监测、预测分析、预警处置、情景推演、报告生成、数据导入与系统管理工作。

系统为浏览器访问的 B/S 应用，建议使用 Chrome、Edge 最新版本，分辨率 1920×1080 及以上；数据大屏建议全屏（F11）展示。文中金额单位统一为“元/公斤”，百分比按百分数展示（如 4.22 表示 4.22%）。

## 2. 登录与账号

### 2.1 访问地址

### 2.2 内置账号

| 账号 | 初始口令 | 角色 | 主要权限 |
| --- | --- | --- | --- |
| admin | Admin@2026 | 系统管理员 | 全部 21 个权限点，含用户、角色、审计、任务调度、系统监控、开放 API |
| analyst01 | Analyst@2026 | 分析师 | 驾驶舱、监测与导出、预测与模型、预警查看、情景、报告、数据查看（12 个权限点） |
| operator01 | Operator@2026 | 业务运营 | 驾驶舱、监测与导出、预警查看/处置/规则、报告查看、情景查看、数据导入（10 个权限点） |
| viewer01 | Viewer@2026 | 观察员 | 驾驶舱、监测、预测、预警、报告、情景的只读查看（6 个权限点） |

系统另内置 3 个区县账号，用于权限隔离与数据范围校验；内置账号共 7 个。账号由管理员在「用户管理」中维护，可修改角色、重置口令或停用。

### 2.3 首次登录与修改口令

1. 打开 `http://127.0.0.1:5177`，进入登录页（截图 00，`docs/screenshots/00-登录页.png`）。
2. 在“用户名”“密码”输入框中填写账号与初始口令，点击「登录」；成功后进入「综合驾驶舱」。
3. 点击右上角姓名下拉菜单，选择「修改密码」；新口令至少 8 位，需包含字母与数字。
4. 修改成功后系统要求重新登录，使用新口令登录即生效。

### 2.4 退出登录

点击右上角姓名下拉菜单，选择「退出登录」。退出后当前凭证立即失效（服务端令牌黑名单），即使复制旧凭证也无法继续访问。连续登录失败不会锁定账号，但会记录在「操作审计」中。

## 4. 通用操作约定

| 约定 | 说明 |
| --- | --- |
| 菜单导航 | 左侧主菜单按业务分组，点击二级菜单进入页面；页面标题与菜单名称一致 |

| 空态提示 | 无数据时显示空态插图与说明；接口异常时提示「数据服务暂不可用」，页面不会白屏 |

| 时间 | 列表时间精确到分钟或秒；日期格式为 `YYYY-MM-DD` |

## 5. 综合驾驶舱

- 进入路径：左侧菜单「总览 / 综合驾驶舱」，或登录成功后的默认首页。
- 页面元素：6 个 KPI 卡（品种数量、区域数量、市场数量、数据记录、平均价格、未处置预警）、价格走势图、区域价格指数、品类占比、最新预警、最新预测摘要（截图 01，`docs/screenshots/01-综合驾驶舱.png`）。
- 关键操作：
  1. 在「价格走势」卡中选择品种、地区，走势图即时刷新；默认展示近 90 天日频序列。
  2. 点击右上角「刷新数据」，重新拉取全部卡片数据。
  3. 点击「最新预警」中的行，跳转「预警信息」并定位该条记录；点击「最新预测摘要」中的行，跳转「短期预测」。
- 结果校验：KPI 数值与下方图表一致；走势图悬停提示显示日期、价格（元/公斤）与同比；无数据时显示“暂无数据”空态。

## 6. 价格监测

- 进入路径：左侧菜单「监测分析 / 价格监测」。
- 页面元素：筛选区（品种、地区、市场类型、日期区间）、4 个指标卡（平均价格、最高价格、最低价格、波动率）、粒度切换（日/周/月）、走势图、价格明细表、分页与「导出 CSV」（截图 02，`docs/screenshots/02-价格监测.png`）。
- 关键操作：
  1. 选择品种、地区、市场类型与日期区间（默认近 30 天），点击「查询」。
  2. 切换「日/周/月」查看不同粒度走势。
  3. 在明细表中翻页查看日期、品种、地区、市场、市场类型、均价、最低价、最高价、成交量、质量标记。
  4. 点击「导出 CSV」，下载当前筛选条件下的明细（UTF-8 BOM，Excel 可直接打开）。
- 结果校验：指标卡与走势、明细同源；导出文件行数与分页总数一致；观察员角色无导出按钮。

## 7. 监测分析

- 进入路径：左侧菜单「监测分析 / 监测分析」。
- 页面元素：筛选区（品种、地区、分析区间 30/60/90 天）、区域价差双柱图、品种比价指数多线图、季节指数柱线图、指标说明卡（截图 03，`docs/screenshots/03-监测分析.png`）。
- 关键操作：
  1. 选择品种、地区与区间，点击「查询」。
  2. 在「区域价差」中比较同一品种不同地区的均价与价差，判断销区溢价与产区折价。
  3. 在「品种比价指数」中查看以区间首日价格为 100 的指数曲线，横向比较涨跌幅度。
  4. 在「季节指数」中查看以 100 为基准的月度指数，高于 100 表示高于全年同期均值。
- 结果校验：图例与 tooltip 数值单位一致；筛选变化后三张图同步刷新；空数据时显示空态。

## 8. 短期预测

- 进入路径：左侧菜单「预测分析 / 短期预测」。
- 页面元素：条件区（品种、地区、预测天数 7/14/30/自定义）、「开始预测」按钮、结果区（历史与预测折线、结论卡、预测明细表、因素贡献条形图）、最近预测、性能概览（截图 04，`docs/screenshots/04-短期预测.png`）。
- 关键操作：
  1. 选择品种、地区与预测天数，点击「开始预测」，等待 1~3 秒返回结果。
  2. 阅读结论卡：趋势方向、预期涨跌幅、风险等级、置信度；折线中阴影带为置信区间，虚线为历史与预测分隔。
  3. 在明细表查看目标日、预测价格、置信区间、置信度、方向、预计变动。
  4. 在「最近预测」中点击历史记录可回看；“性能概览”展示在用模型的平均 MAPE 与方向准确率。
- 结果校验：预测起始日与最新价格日期衔接；置信区间上下界包住点预测；提示“预测结果基于历史回测选择的最优模型，属于统计推断，不构成交易建议”。

## 9. 批量预测

- 进入路径：左侧菜单「预测分析 / 批量预测」。
- 页面元素：品种多选、地区多选、预测天数、组合数量、「开始批量预测」按钮、进度区、结果表、「导出 CSV」（截图 05，`docs/screenshots/05-批量预测.png`）。
- 关键操作：
  1. 多选品种与地区（可交叉组合），设置预测天数，确认组合数量不超过 200。
  2. 点击「开始批量预测」，页面每 1.5 秒轮询状态：排队中 → 执行中 → 已完成。
  3. 结果表按“品种 × 地区”一行展示预测价、置信区间、方向、模型 MAPE。
  4. 点击「导出 CSV」下载全部结果。
- 结果校验：进度条达到 100%，状态为“已完成”；导出文件行数与组合数量一致；部分组合未生成时状态为“部分完成”并提示。

## 10. 模型管理

- 进入路径：左侧菜单「预测分析 / 模型管理」。
- 页面元素：4 个 KPI（模型总数、生效模型、平均 MAPE、平均方向准确率）、筛选区、「开始训练」「刷新」、模型列表（版本、算法、MAPE、RMSE、方向准确率、训练时间、在用状态）、操作列（激活、回测、详情）（截图 06，`docs/screenshots/06-模型管理.png`）。
- 关键操作：
  1. 按品种、算法、状态筛选模型。
  2. 点击「开始训练」，选择“全部品种”或指定品种，训练完成后列表自动刷新并生成新版本。
  3. 点击「激活」，将该版本设为在用模型；同类算法每个组合仅保留一个在用版本。
  4. 点击「回测」查看近 60 天实际值与预测值对比、误差指标与特征重要性；点击「详情」查看训练参数与指标。
- 结果校验：激活后“在用”标记唯一；平均 MAPE 越低、方向准确率越高表示模型越优；训练与激活需 `model:manage` 权限。

## 11. 模型监测

- 进入路径：左侧菜单「预测分析 / 模型监测」。
- 页面元素：筛选区（品种、地区、漂移等级、基准窗口 30/60/90 天）、「重训漂移模型」、模型列表（MAPE、近期 MAPE、变化、PSI、漂移等级、训练时间、操作）、算法对比面板与 PSI 说明（截图 06b，`docs/screenshots/06b-模型监测.png`）。
- 关键操作：
  1. 选择筛选条件，查看各在用模型的 PSI 与漂移等级。
  2. 点击行内「重训」或页头「重训漂移模型」，系统重训该组合并回写新版本。
  3. 点击「对比」查看该品种/地区下 4 类算法的 MAPE 与方向准确率对比。
- 结果校验：PSI `<0.1` 为平稳、`0.1~0.25` 为关注、`>0.25` 为漂移；出现“漂移”时建议先重训，再检查数据源是否变化。

## 12. 预警信息

- 进入路径：左侧菜单「预警管理 / 预警信息」。
- 页面元素：统计卡（未处置、近 30 天总量、等级与状态分布、趋势、命中率）、筛选区（状态、等级、品种、地区）、「立即扫描」、预警列表、详情抽屉、处置对话框（截图 07，`docs/screenshots/07-预警信息.png`）。
- 关键操作：
  1. 按状态、等级、品种、地区筛选并点击「查询」。
  2. 点击行内「详情」查看触发规则、触发值、阈值与口径说明。
  3. 点击「处置」，选择「确认处置（处理中）」或「关闭预警（已关闭）」，填写处置说明；关闭预警必须填写处置结果后点击「提交处置」。
  4. 具备 `alert:handle` 权限的账号可点击「立即扫描」，按当前规则重新评估近 30 天数据并生成新预警。
- 结果校验：处置后状态即时变化，处置人与处置时间写入列表；关闭操作记入「操作审计」；SLA 要求 24 小时内完成处置。

## 13. 预警规则

- 进入路径：左侧菜单「预警管理 / 预警规则」。
- 页面元素：规则列表（名称、类型、比较符、阈值、窗口天数、等级、启停状态、命中次数）、「新增规则」「刷新」、编辑/删除按钮（截图 08，`docs/screenshots/08-预警规则.png`）。
- 关键操作：
  1. 点击「新增规则」，填写名称、品种（可指定地区）、规则类型（价格阈值/波动率/同比/价差）、比较符、阈值（须大于 0）、窗口天数（1~365）、等级与通知渠道，点击「保存」。
  2. 点击「编辑」修改规则；点击「删除」需二次确认，历史预警记录保留。
  3. 使用列表开关启用或停用规则，规则启用后每次扫描自动判断是否触发。
- 结果校验：启停状态与开关一致；命中次数随扫描增加；停用规则不再产生新预警。

## 14. 情景推演

- 进入路径：左侧菜单「情景推演」。
- 页面元素：情景名称、情景模板（天气、运输、政策、替代品）、品种与地区、推演天数滑杆（7~30 天）、四类冲击滑杆（产量、运费、政策、替代品，-30%~+30%）、天气等级滑杆（0~3）、「开始推演」「重置」、结果区（综合价格变化、价格区间、风险等级、基准与推演曲线、因素贡献、应对建议）、历史列表（截图 09，`docs/screenshots/09-情景推演.png`）。
- 关键操作：
  1. 选择情景模板，系统自动带出推荐冲击参数；也可手工调整各滑杆。
  2. 选择品种、地区与推演天数，点击「开始推演」。
  3. 阅读结果：综合价格变化与低/中/高价格区间、风险等级、因素贡献排序与应对建议。
  4. 在历史列表中回看记录，点击「删除」移除不需要的记录；点击「刷新记录」重新拉取。
- 结果校验：基准曲线与推演曲线同时展示；滑杆数值与结果说明一致；空数据时显示“暂无情景模板”或空态。

## 15. 报告中心

- 进入路径：左侧菜单「报告中心」。
- 页面元素：筛选区（类型、时间）、「下载模板」（日报/周报/月报 Excel 模板）、「刷新」、「生成报告」、报告列表、预览抽屉、下载菜单（HTML/Markdown/Excel）（截图 10，`docs/screenshots/10-分析报告.png`）。
- 关键操作：
  1. 点击「生成报告」，选择报告类型（日报/周报/月报）、统计周期、品种与地区，确认后生成。
  2. 点击「查看」打开正文，含价格概况、波动与预警、预测摘要、结论建议。
  3. 点击「下载」选择 HTML 或 Markdown；点击「下载 Excel」得到含“概览 / 价格与预测 / 预警摘要”三张工作表的 `.xlsx`。
  4. 通过右上角「下载模板」下载空白 Excel 模板，供线下填报或核对口径。
- 结果校验：报告生成后出现在列表顶部；Excel 可正常打开且三张工作表齐全；删除报告需二次确认。

## 16. 数据治理

### 16.1 数据源管理

- 进入路径：左侧菜单「数据治理 / 数据源管理」。
- 页面元素：4 个 KPI（数据源数量、已连接、累计记录数、最近同步）、数据源列表（名称、类型、协议、责任单位、状态、最近同步、记录数）、「新增数据源」「刷新」、编辑/删除（截图 11，`docs/screenshots/11-数据源管理.png`）。
- 关键操作：新增或编辑数据源后保存；对数据源执行同步刷新同步时间与记录数；删除需二次确认。
- 结果校验：状态为“已连接/正常”表示可用；记录数随同步增长。

### 16.2 数据质量

- 进入路径：左侧菜单「数据治理 / 数据质量」。
- 页面元素：完整率、重复率、异常数、总数指标卡，分品种质量分布图，质量问题列表（日期、价格、问题类型、明细、状态）、类型与状态筛选、「处置」（截图 12，`docs/screenshots/12-数据质量.png`）。
- 关键操作：筛选问题记录，点击「处置」，选择“修正数据（标记为已处理）”或“排除记录（标记为已排除）”，点击「确认处置」。
- 结果校验：处置后状态变化；质量问题总量与列表统计一致；48 条基线问题（正常 84,126 / 疑似异常 329 / 缺失估算 205）可在页面汇总中核对。

### 16.3 数据导入

- 进入路径：左侧菜单「数据治理 / 数据导入」。
- 页面元素：文件上传区、数据源选择、「下载模板」「刷新」「开始导入」、导入结果（总行数、成功、失败、错误明细）、最近导入任务表（截图 13，`docs/screenshots/13-数据导入.png`）。
- 关键操作：
  1. 点击「下载模板」取得 CSV 模板，按表头填写（仅支持 `.csv`，单次一个文件）。
  2. 选择文件与数据源，点击「开始导入」。
  3. 查看总行数、成功数与失败数；失败行显示行号与原因，并生成质量问题记录。
- 结果校验：成功数 + 失败数 = 总行数；导入完成后驾驶舱缓存主动失效；失败原因可据此修正后重传。

## 18. 系统监控

- 进入路径：左侧菜单「系统管理 / 系统监控」（需 `admin:task` 权限）。
- 页面元素：6 个指标卡（QPS、平均耗时、P95、错误率、缓存命中率、近一小时请求数）、分钟时序双轴图（30/60/120 分钟切换）、日志检索（级别、关键词、条数、查询/重置）、结构化日志表（可展开查看 JSON）、服务状态 8 项（数据库、缓存、对象存储、调度器、邮件通道、日志文件、指标采集、运行时长）、「发送测试邮件」「立即检查到期任务」（截图 22，`docs/screenshots/22-系统监控.png`）。
- 关键操作：
  1. 查看指标卡与时序图定位突发流量或慢接口；悬停显示 QPS、平均耗时（ms）与错误率（%）。
  2. 在日志检索中选择级别、输入路径或事件关键字，点击「查询」；点击行首箭头展开 request_id、状态码、耗时与缓存命中详情。
  3. 查看服务状态标签（正常/降级/已暂停）；点击「发送测试邮件」验证邮件通道，点击「立即检查到期任务」触发一次调度检查。
- 结果校验：页面每 30 秒自动刷新；手动操作成功有成功提示，失败提示“数据服务暂不可用”；邮件可在 `http://127.0.0.1:8025` 查看。

## 21. 开放 API

- 进入路径：左侧菜单「开放 API」（仅管理员）。
- 页面元素：接入说明（接口地址、鉴权方式、错误码、密钥安全提示）、调用方列表（Client Key、密钥状态、限流、累计调用、最近调用、启用开关、轮换/删除）、「新建调用方」、调用统计（总调用、平均耗时、错误率、近 7 天趋势、Top 路径、调用流水）、接口清单与调试面板（截图 19，`docs/screenshots/19-开放API.png`）。
- 关键操作：
  1. 点击「新建调用方」，填写名称、每分钟限流（默认 60 次/分）与说明，点击「创建」。
  2. 在「调用方密钥」弹窗复制 `client_key` 与 `secret` 并点击「我已保存」；密钥仅展示一次。
  3. 使用 `Authorization: Bearer <token>` 或 `X-Api-Key: <client_key>` 调用；点击「复制 cURL」获取示例。
  4. 泄漏时点击「轮换」生成新密钥，旧密钥立即失效；停用后携带该密钥的请求返回 `E4010`。
- 结果校验：调用统计与流水随调用增长；超过限流返回 HTTP 429 与 `E4290`，参考 `Retry-After` 重试；接口清单包括 `/api/open/v1/prices`、`/forecast`、`/alerts`、`/reports`、`/metrics`。

## 22. 常见问题

| 序号 | 现象 | 处理方式 |
| --- | --- | --- |
| 1 | 登录提示“用户名或密码不正确” | 确认大小写与输入法；管理员可在「用户管理」重置密码；连续失败会记入审计 |
| 2 | 菜单比预期少或按钮置灰 | 当前角色无对应权限点；由管理员在「角色权限」中勾选并保存 |
| 3 | 图表空白或显示“暂无数据” | 确认筛选条件下有数据；点击「刷新数据」重新拉取；确认后端 8017 已启动 |
| 4 | 页面提示“数据服务暂不可用” | 后端未启动或接口异常；检查 `npm run dev` 是否运行、8017 端口是否可访问 |
| 5 | 批量预测提交后无结果 | 确认组合数量未超 200；查看状态是否为“部分完成”；刷新页面重试 |
| 6 | 报告下载没有 Excel 选项 | 报告未生成完成或无下载权限；确认账号具备报告权限并等待生成完成 |
| 7 | 测试邮件收不到 | 检查 Mailpit 是否启动（8025）；确认「服务状态」中邮件通道为正常；查看发送记录失败原因 |
| 8 | 导入或处置后页面数据未更新 | 缓存默认 30 秒过期；点击「刷新」或等待后重试 |
| 9 | 提示数据库连接失败 | 执行 `npm run infra:up` 检查 MySQL（13306）与库 `agri_price`；确认端口未被占用 |
| 10 | 导出 CSV 中文乱码 | 文件已带 UTF-8 BOM，可直接双击；或用 Excel「数据 → 自文本」选择 UTF-8 |
| 11 | 开放 API 返回 429 / E4290 | 触发调用方限流；按 `Retry-After` 稍后重试，或由管理员调高限流值 |
| 12 | 通知铃铛一直为 0 | 当前账号无未读通知；处置一条预警或完成一次导入后再查看 |

## 23. 口径与快捷操作说明

| 项目 | 口径 |
| --- | --- |
| 价格单位 | 元/公斤；百分比字段按百分数展示（4.22 表示 4.22%） |
| 方向准确率 | 主口径为 30 日趋势累计方向命中率（7 日移动平均去噪），基线均值 77.89%，目标 ≥65%；接口另披露 7 日累计与单日参考口径 |
| 模型精度 | 30 个在用模型 MAPE 均值 4.22%（区间 1.54%~9.61%），目标 ≤12%~15% |
| PSI 阈值 | `<0.1` 平稳、`0.1~0.25` 关注、`>0.25` 漂移；基线 30 个模型为 4 平稳 / 18 关注 / 8 漂移，平均 0.2565 |
| 预警 SLA | 24 小时内完成处置；高等级预警与任务失败同步发送邮件 |
| 缓存 | 驾驶舱等读接口缓存约 30 秒，导入/处置后会主动失效 |
| 数据规模 | 价格记录 84,660 条（60 个序列 × 1,411 天）、品种 5 / 地区 6 / 市场 12 / 数据源 5 |
| 快捷入口 | 预警行 → 预警信息；预测行 → 短期预测；铃铛 → 通知中心；`/screen` → 数据大屏 |
