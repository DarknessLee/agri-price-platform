# 接口契约（V1.0，冻结后只增不改）

- 服务基址：`http://127.0.0.1:8017`（开发期前端通过 Vite 代理 `/api` → 该地址）
- 前缀：所有业务接口以 `/api` 开头；`/api/docs` 为 Swagger UI，`/api/openapi.json` 为 OpenAPI 文档
- 鉴权：除 `POST /api/auth/login`、`GET /api/health` 外均需请求头 `Authorization: Bearer <token>`
- 时间：日期 `YYYY-MM-DD`，时间 `YYYY-MM-DDTHH:MM:SS`；金额/价格数值保留 2～4 位小数；百分比字段为百分数数值（如 `3.25` 表示 3.25%）

## 0. 通用约定

**统一响应包**

```json
{ "code": 0, "message": "ok", "data": {} }
```

- 成功 `code = 0`，`message = "ok"`；分页时 `data = { "list": [], "total": 0, "page": 1, "page_size": 20 }`
- 失败返回 HTTP 4xx/5xx，body：`{ "code": "E4001", "message": "错误描述", "data": null }`

**缓存与降级**

- 只读聚合接口（`/api/dashboard/summary|trend|region-heat|category-share`、`/api/meta/dicts`、`/api/forecast/performance`、`/api/prices/series`）优先读取 Redis 缓存，响应头返回 `X-Cache: HIT` 或 `X-Cache: MISS` 便于观测；缓存 TTL 30～300 秒。
- 数据导入、数据源同步、预警扫描成功后主动清理相关缓存前缀；Redis 不可用时接口自动降级为直连数据库并返回 `X-Cache: MISS`，不影响功能可用性。
- 注销登录后令牌写入黑名单（TTL 为剩余有效期），旧令牌再访问任意受保护接口返回 `E4010`。

**错误码**

| code | HTTP | 含义 |
| --- | --- | --- |
| E4001 | 400 | 参数校验失败 |
| E4002 | 400 | 业务规则不满足（如重复导入、状态不允许） |
| E4010 | 401 | 未登录或令牌失效 |
| E4030 | 403 | 权限不足 |
| E4040 | 404 | 资源不存在 |
| E4090 | 409 | 唯一约束冲突（用户名/编码重复） |
| E5000 | 500 | 服务内部异常（含 trace_id 便于排查） |

| `admin:user` / `admin:role` / `admin:base` / `admin:audit` / `admin:task` | 后台管理各项 |
