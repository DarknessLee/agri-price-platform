# 数据字典（V1.0）

> 数据库：SQLite 3（文件 `.runtime/agri.db`，WAL 模式，外键开启，`temp_store=MEMORY`）。
> 表命名：`sys_*` 系统与权限，`dim_*` 主数据，其余为事实表。所有时间为本机时间 `datetime.now()`，价格日期为自然日 `date`。
> 统一口径：价格单位默认「元/公斤」；百分比字段（`yoy_pct`、`mape`、`direction_acc` 等）以「百分数」存储（如 `4.22` 表示 4.22%）。

## 1. 系统与权限（5 张）

### sys_role 角色
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | TEXT PK | 角色标识：admin / analyst / operator / viewer |
| name | TEXT | 角色名称：系统管理员 / 分析师 / 业务运营 / 观察员 |
| description | TEXT | 角色说明 |

### sys_permission 权限点
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | TEXT PK | 权限点标识，如 `forecast:run` |
| name | TEXT | 中文名称 |
| module | TEXT | 所属模块：dashboard / monitor / forecast / model / alert / scenario / report / data / admin |
| sort | INT | 排序 |

共 21 个权限点：`dashboard:view`；`monitor:view`、`monitor:export`；`forecast:view`、`forecast:run`、`model:manage`；`alert:view`、`alert:handle`、`alert:rule`；`scenario:view`、`scenario:run`；`report:view`、`report:generate`；`data:view`、`data:import`、`data:source`；`admin:user`、`admin:role`、`admin:base`、`admin:audit`、`admin:task`。

### sys_role_permission 角色-权限关联
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INT PK | 自增 |
| role_key | TEXT FK sys_role.key | 角色 |
| perm_key | TEXT FK sys_permission.key | 权限点 |

唯一约束 `uq_role_perm(role_key, perm_key)`。角色权限：admin 全部 21 项；analyst 12 项；operator 10 项；viewer 6 项（只读）。

### sys_menu 菜单
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| key | TEXT PK | 菜单标识 |
| title | TEXT | 菜单标题 |
| path | TEXT | 前端路由路径 |
| icon | TEXT | Element Plus 图标名 |
| permission | TEXT | 可见所需权限点（空表示分组节点） |
| parent_key | TEXT | 父菜单 key（空为顶级） |
| sort | INT | 排序 |

菜单树由 `GET /api/meta/menus` 按当前用户权限过滤后返回。

### sys_user 用户
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INT PK | 自增 |
| username | TEXT UNIQUE | 登录名 |
| password_hash | TEXT | PBKDF2-SHA256（12 万轮，`salt$hash` 形式） |
| display_name | TEXT | 姓名 |
| role_key | TEXT FK sys_role.key | 角色 |
| org | TEXT | 所属机构 |
| phone / email | TEXT | 联系方式 |
| status | TEXT | 启用 / 停用 |
| last_login_at | DATETIME | 最近登录时间 |
| created_at | DATETIME | 创建时间 |

内置账号 7 个；口令不以明文存储，重置由管理员触发写入新散列。

## 8. 关系与约束摘要

- `price_record` 通过 `(variety_id, region_id, market_id, market_type, price_date)` 唯一约束保证同一市场价格点唯一。
- `dim_market.region_code → dim_region.code`、`sys_user.role_key → sys_role.key`、`sys_role_permission` 双向外键均启用 SQLite 外键约束。
- 事实表对主数据的引用均为 `ON DELETE` 默认（RESTRICT），删除品种/地区前需先清理业务数据。
- 权限点 21 个、角色 4 个、菜单 20+ 个由种子脚本 `backend/app/seed.py` 幂等写入，可 `npm run seed` 全量重建。
