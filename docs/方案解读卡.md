# 方案解读卡：农产品价格预测分析系统

> 依据：《农产品价格预测分析系统开发书（草案）V0.1》+《软著 Demo 开发手册》。
> 取舍唯一标准：**本机能否演示**。方案中的重型能力默认暂缓。

## 1. 这个项目要做什么

- **一句话定位**：面向农业主管部门、批发市场、合作社与金融机构的农产品价格"采集—治理—监测—预测—预警—报告"一体化分析平台。
- **核心闭环**：
  1. 价格数据接入 → 质量校验 → 统一口径入库（品种 / 地区 / 市场 / 日频）。
  2. 监测分析：多品种多区域趋势、同比环比、季节指数、波动率、区域价差、品种比价。
  3. 预测：短期 7～30 天点预测 + 区间 + 涨跌方向 + 影响因素解释，模型可回测、可切换版本。
  4. 预警：规则阈值 / 波动率 / 同比异常 → 分级预警 → 认领处置 → 闭环归档。
  5. 情景模拟与报告：气象减产、运输成本、政策冲击等情景推演，输出日报/周报/月报与开放 API。
- **明确不做**：真实外部数据源对接（演示用定时同步模拟）、短信/邮件真实推送、K8s 集群部署、多租户、深度学习模型（LSTM/TFT）、全文检索。

## 2. 产品形态

- 形态：**B/S 单机演示**——一个后端进程 + 一个浏览器访问的前端；前端可静态托管，由后端或 Vite 提供。
- 部署：本机 / 内网均可；不需要 Docker/K8s；数据库文件随项目走，一键重建演示数据。
- 使用场景与规模：单机 1～10 人演示；角色 4 类（系统管理员 / 分析师 / 监测员 / 领导·访客）。

## 3. 技术栈与可替换性

| 层 | 方案选型 | 可否替换 | 替代方案与代价 | 备注（硬约束） |
| --- | --- | --- | --- | --- |
| 前端 | Vue3 + Vite + TS + ECharts | 可 | React + AntV，重写页面成本高 | 方案指定 Vue3/ECharts |
| UI 组件 | Element Plus | 可 | Naive UI / Ant Design Vue，改动中等 | 中文管理端适配好 |
| 后端 | FastAPI（Python 3.12） | 可 | Spring Boot（JVM 依赖重，演示成本高） | 方案指定 Python 服务 |
| 数据库 | SQLite 文件 + SQLAlchemy | 可 | PostgreSQL+TimescaleDB（需安装运维，演示过重） | 方案指定 PG，演示降级，ORM 保持可迁移 |
| 缓存 | 进程内 TTL 缓存 | 可 | Redis（需额外服务） | 演示价值低 |
| 消息队列 | 不引入（同步调用 + 内置任务表） | 可 | Kafka（重型） | 暂缓 |
| 调度 | 进程内任务表 + 手动触发 | 可 | Airflow/DolphinScheduler（重型） | 暂缓 |
| 模型管理 | 数据库模型版本表 + 本地模型文件 | 可 | MLflow（重型） | 暂缓 |
| 对象存储 | 本地文件系统 `data/` | 可 | MinIO（重型） | 暂缓 |
| 建模 | numpy / pandas / statsmodels / scikit-learn | 可 | Prophet/深度模型（安装重、不可解释） | 方案指定机器学习，按需选型 |
| 部署 | 本机脚本（PowerShell）+ 可选 Nginx 静态托管 | 可 | Docker Compose（可选，不强制） | 演示优先 |

不可替换项：无客户硬约束；中文界面、国产化友好为默认要求。

## 4. MVP 与分期

| 优先级 | 内容 | 演示价值 | 成本 | 说明 |
| --- | --- | --- | --- | --- |
| 一期必做 | 登录与 RBAC、驾驶舱、价格监测（趋势/同比环比/价差/比价/季节）、短期预测（点+区间+方向+解释）、模型回测与管理、预警规则与处置闭环、数据源与质量、报告生成、审计日志、开放 API | 高 | 高 | 构成完整可演示闭环 |
| 二期增强 | 批量预测、情景模拟、用户/角色/菜单管理、任务调度、移动端自适应 | 中 | 中 | 演示加分项，本次一并实现 |
| 三期可选 | 中期 1～3 个月预测、产区气象接入、短信/邮件通道、多租户、智能问答 | 低 | 高 | 标注暂缓，不做 |

建议最小交付集：一期 + 情景模拟 + 批量预测 + 截图与操作手册（可用于软著演示与评审）。

## 5. 待用户确认（按默认推进，不阻塞）

1. 产品形态为单机 B/S（非桌面端、非 K8s）——默认采用。
2. 数据为系统生成的业务级种子数据，不接真实外部价格源——默认采用。
3. 产品名与版本：**农产品价格预测分析系统 V1.0**——默认采用。
4. 是否另行制作软著登记材料（60 页源码/手册/申请表）——默认不做，仅做演示系统与文档。
5. 是否需要 Docker 交付形态——默认仅提供本机脚本，Docker 为可选说明。
