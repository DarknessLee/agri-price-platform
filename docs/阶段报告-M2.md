## 2. 范围

### 2.1 本阶段实现

- 数据模型：新增 `sys_notification`、`open_api_client`、`open_api_call` 三张表（库内共 27 张），配置项新增漂移、SLA、通知保留与限流常量。
- 后端服务：`services/governance.py`（PSI 漂移）、`services/notification.py`（通知）、`services/open_api_gate.py`（密钥鉴权 + 限流 + 流水）。
- 后端接口：`GET /api/models/drift`；批量预测异步化（`POST /api/forecast/batch` 立即返回）；`GET /api/reports/{id}/download?format=xlsx`、`GET /api/reports/template`；`/api/notifications/*`；`GET /api/alerts/sla`；`/api/open-clients/*`（CRUD/轮换/用量）。
- 通知链路：预警扫描、预警确认、预警关闭、数据导入、模型训练、报告生成、调度任务执行 7 条链路写入站内通知。
- 前端：`/screen` 数据大屏（全屏深色、四图两表、30 秒刷新）、`NotificationBell` 顶栏通知中心、`/forecast/drift` 模型监测、`OpenApi` 调用方密钥与调用统计、`ReportCenter` Excel 下载与模板。
- 门禁：数据库门禁扩到 37 项（含 3 张新表与行数断言）；接口门禁扩到 188 项（新增漂移、批量异步、xlsx、通知、SLA、开放 API 密钥/限流段）；端到端扩到 21 项（含 `/screen` 与 `/forecast/drift`）。

### 2.2 不在本阶段范围

- 外部通知通道（短信/邮件/企业微信）——站内通知已满足闭环留痕，外部通道需账号与网络审批。
- 深度模型（LSTM/Transformer）与 AutoML——数据规模与算力不匹配。
- 灰度发布（按比例分流）——单机单实例无流量调度需求，漂移监控 + 重训已覆盖主要风险。
- 生产化组件（Kafka/MinIO/MLflow/Airflow/K8s）——见 `DECISIONS.md` D05/D15。

## 5. 关键设计说明

- **漂移口径（D21）**：PSI 比较「最近 90 天日收益率」与「之前 180 天日收益率」，10 分箱按基线分位数切分。首版按 30/90 天波动率计算时，30 天窗口每箱样本仅 3 个、且波动率水平台阶导致 30/30 模型全判漂移；改日收益率后等级分布恢复区分度（4/18/8），并在契约中写明窗口选择理由。
- **批量异步（D17）**：后台 daemon 线程 + 独立 `SessionLocal`，进度与错误写回 `forecast_batch`，前端沿用轮询；不使用消息队列，符合单机部署形态。
- **通知与 SLA（D18）**：通知与业务同事务写入（`commit=False` + 失败兜底），SLA 以 `alert_record.handled_at - alert_date` 计算，默认 24 小时，空数据返回 0 而非 null。
- **开放 API 治理（D19）**：`X-Api-Key` 优先、否则 Bearer；限流用 Redis INCR+EXPIRE（分钟窗口），Redis 不可用时退化为进程内计数并保持 429 语义；流水 7 天保留，每次调用顺带清理。

## 6. 已知限制

1. 漂移 PSI 依赖价格流水分布，节假日等结构性月份会自然抬升 PSI，需结合 `recent_mape` 与业务日历判读，不宜只看等级。
2. `recent_mape` 依赖近 30 天 `backtest_record`；未跑回测时回退训练期留出 MAPE，此时 `mape_change` 为 0。
3. 通知仅站内通道，未接短信/邮件；通知未做缓存，已读状态实时查库。
4. 开放 API 限流为单机 Redis 分钟窗口，非分布式令牌桶；多实例部署需改为集中式限流。
5. 数据大屏按 1680×1050 以上设计，移动端未做响应式适配。
6. 方向准确率主口径为 30 日趋势累计命中率（77.89%），7 日累计口径约 52%~63%、单日约 50%，短周期方向预测仍受日频噪声限制。

## 7. 后续计划

1. 接入外部通知通道（邮件/企业微信）与通知偏好设置，替换站内单通道。
2. 漂移告警联动：PSI 超阈值自动触发重训任务并写入通知，形成「监测—重训—通知」闭环。
3. 分布式限流与多实例部署：Redis 全局限流 + 无状态鉴权，适配 K8s 横向扩容。
4. 中期预测（1~3 个月）：按月度粒度扩展 horizon，补齐方案中期经营决策场景。
5. 数据大屏增加轮播与告警声光提示，适配值班室常驻展示。
