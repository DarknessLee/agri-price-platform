# 用户手册（V1.0）

> 面向：主管部门业务人员、批发市场管理员、合作社/金融机构分析人员、系统管理员。
> 系统形态：浏览器访问的 B/S 应用，前端 `http://127.0.0.1:5177`，后端接口 `http://127.0.0.1:8017`（生产构建后由后端 `8017` 直接托管前端页面）。

## 1. 启动与登录

1. 在项目根目录执行 `npm run infra:up`：脚本会检查 MySQL（13306）与 Redis（16379）容器、幂等创建 `agri_price` 库与 `agri` 账号并验证连通性；若本机尚无容器，先用 `docker compose -f deploy/docker-compose.yml up -d` 启动。
2. 首次使用执行 `npm run seed` 生成初始数据；随后执行 `npm run dev`，等待日志出现 `Uvicorn running on http://127.0.0.1:8017` 与 `Local: http://127.0.0.1:5177/`（校验通过后浏览器打开 `http://127.0.0.1:5177`）。
3. 打开登录页，输入用户名与口令，点击「登录」；成功后进入「综合驾驶舱」。
4. 内置账号（首次启动自动创建，可在「用户管理」中修改或停用）：

| 账号 | 初始口令 | 角色 | 主要权限 |
| --- | --- | --- | --- |
| admin | Admin@2026 | 系统管理员 | 全部 21 个权限点，含用户/角色/审计/任务调度 |
| analyst01 | Analyst@2026 | 分析师 | 驾驶舱、监测与导出、预测与模型、预警查看、情景、报告、数据查看 |
| operator01 | Operator@2026 | 业务运营 | 驾驶舱、监测与导出、预警查看/处置/规则、报告查看、情景查看、数据导入 |
| viewer01 | Viewer@2026 | 观察员 | 驾驶舱、监测、预测、预警、报告、情景的只读查看 |

4. 登录后右上角显示姓名与角色；下拉菜单可「修改密码」（修改后需重新登录）或「退出登录」。退出后当前凭证立即失效（服务端令牌黑名单），即使复制旧凭证也无法继续访问。
5. 口令要求：至少 8 位，包含字母与数字；连续登录失败不会锁定账号，但会记录在操作审计中。

### 角色与权限

系统采用「角色 → 权限点 → 菜单/按钮」三级控制：无权限的菜单不显示，无权限的按钮置灰或隐藏，后端接口同样校验权限点（越权访问返回 `E4030` 并跳转「无权限」页）。角色权限对照见 `docs/接口契约.md` §0。

## 2. 综合驾驶舱

- 入口：菜单「总览 / 综合驾驶舱」。
- 页面内容：6 个 KPI（品种数量、区域数量、市场数量、数据记录、平均价格、未处置预警）、价格走势（可按品种与地区筛选近 90 天日频序列）、区域价格指数横向对比、品类占比环形图、最新预警与最新预测摘要。
- 操作：修改「品种」「地区」下拉即时刷新走势；点击右侧「刷新数据」重新拉取全部卡片；点击预警行跳转「预警信息」，点击预测行跳转「短期预测」。
- 说明：KPI 中「平均价格」为全品种最新日均价，「未处置预警」为状态非「已关闭」的预警数。

## 3. 价格监测

- 入口：菜单「监测分析 / 价格监测」。
- 筛选：品种、地区、市场类型（批发/零售）、日期区间，点击「查询」生效；分页浏览明细分页表格。
- 表格字段：日期、品种、地区、市场、市场类型、均价、最低价、最高价、成交量、质量标记。
- 图表：按「日/周/月」切换粒度查看走势；顶部指标卡展示区间平均价、最高价、最低价、波动率。
- 导出：点击「导出 CSV」下载当前筛选条件下的价格明细（带 UTF-8 BOM，Excel 可直接打开）。观察员角色无导出权限。

## 4. 监测分析

- 入口：菜单「监测分析 / 监测分析」。
- 区域价差：同一品种不同地区的价格双柱对比，用于识别销区溢价与产区折价。
- 品种比价：以区间首日价格为 100 的指数曲线，横向比较不同品种涨跌幅度。
- 季节指数：以 100 为基准的月度季节指数柱线图，判断季节性规律。
- 指标口径：同比 = 与去年同期比；环比 = 与上期比；波动率 = 近 30 日价格标准差/均价；价差 = 最高地区价 − 最低地区价。

## 5. 短期预测

- 入口：菜单「预测分析 / 短期预测」。
- 操作：选择品种、地区与预测天数（默认 14 天），点击「开始预测」，等待 1~5 秒返回结果。
- 结果区：历史 + 预测折线（含置信区间带、历史/预测分隔线）、结论卡（趋势、预期涨跌幅、风险等级、置信度）、预测明细表（目标日、点预测、区间、置信度、方向）、因素贡献条形图（同比、季节、成本、运费、气象、节假日等）。
- 回看：「最近预测」列表可点击任意一条回看历史结果；「性能概览」展示在用模型的平均 MAPE 与方向准确率（主口径为 30 日趋势累计方向命中率，接口同时返回 7 日/单日参考口径与口径说明）。
- 提示：预测结果基于历史回测选择的最优模型，属于统计推断，不构成交易建议。

## 6. 批量预测

- 入口：菜单「预测分析 / 批量预测」。
- 操作：多选品种与地区（可交叉组合），设置预测天数，点击「开始批量预测」；任务提交后立即返回并进入后台线程执行，页面每 1.5 秒轮询进度条与状态（排队中 → 执行中 → 已完成），执行过程中已完成的组合会逐步出现。
- 结果：每个「品种 × 地区」一行，含预测价、区间、方向、该组合模型 MAPE；支持「导出 CSV」。
- 规模：默认最多 200 个组合；实测 30 个组合 × 14 天约 2 秒完成，压测 1,800 点耗时 4.27 秒，按同口径外推 1 万点约 24 秒（验收目标 ≤10 分钟）。

## 7. 模型管理

- 入口：菜单「预测分析 / 模型管理」。
- 列表：按品种展示 4 类算法（季节分解、Holt-Winters、梯度提升回归、回测加权组合）的版本、MAPE、RMSE、方向准确率、训练时间与在用状态。
- 训练：点击「训练模型」，可选择「全部品种」或指定品种；训练完成后自动刷新列表并生成新版本。
- 启用：点击「启用」将指定版本设为在用模型，同类算法每个组合仅一个在用版本。
- 回测：点击「回测」打开对话框，查看近 60 天实际 vs 预测曲线、误差指标与特征重要性。
- 权限：训练与启用需要 `model:manage`（管理员、分析师），观察员仅可见。

## 8. 预警信息

- 入口：菜单「预警管理 / 预警信息」。
- 统计卡：未处置数量、近 30 天总量、按等级与状态分布、趋势、命中率。
- 筛选与分页：按状态、等级、品种、地区筛选预警记录。
- 处置：点击行内「处置」打开对话框；「标记处理中」填写处置说明；「关闭预警」需额外填写处置结果，关闭后进入「已关闭」状态并记入审计。
- 详情：点击「详情」抽屉查看触发规则、触发值、阈值与口径说明。
- 立即扫描：具备 `alert:handle` 权限的用户可点击「立即扫描」，按当前规则重新评估近 30 天数据并生成新预警。

## 9. 预警规则

- 入口：菜单「预警管理 / 预警规则」。
- 列表：规则名称、类型（价格阈值/波动率/同比/价差）、比较符、阈值、窗口天数、等级、启停状态、命中次数。
- 新增/编辑：填写名称、品种（可指定地区）、规则类型、比较符、阈值（必须大于 0）、窗口天数（1~365）、等级与通知渠道。
- 启停：列表开关即时生效；删除需二次确认（历史预警记录保留）。

## 10. 情景推演

- 入口：菜单「情景推演」。
- 模板：天气、运输、政策、替代品四类，选择模板后自动带出推荐冲击参数。
- 操作：选择品种、地区、推演天数，调整冲击参数（产量、运费、政策、替代品、天气等级），点击「开始推演」。
- 结果：综合价格变化、价格区间（低/中/高）、风险等级、基准 vs 推演曲线、因素贡献、应对建议。
- 历史：下方列表可回看并删除历史推演记录。

## 11. 分析报告

- 入口：菜单「报告中心」。
- 生成：选择报告类型（日报/周报/月报）、统计区间、品种与地区范围，点击「生成报告」。
- 查看：点击报告标题打开正文（含价格概况、波动与预警、预测摘要、结论建议）。
- 下载：支持 HTML、Markdown 与 Excel（.xlsx）三种格式；Excel 含「概览 / 价格与预测 / 预警摘要」三张工作表，适合直接汇入汇报材料。
- 模板：报告中心右上角「下载模板」可按日报/周报/月报下载空白 Excel 模板。
- 删除：具备权限的用户可删除报告（二次确认）。

## 12. 数据治理

- 数据源管理（`数据治理 / 数据源管理`）：查看数据源名称、类型、协议、责任单位、状态、最近同步时间、记录数；管理员可新增/编辑/删除，点击「同步」刷新同步时间与记录数。
- 数据质量（`数据治理 / 数据质量`）：查看完整率、重复率、异常数、总数与分品种质量分布；在「质量问题」列表按类型筛选，对问题执行「修正」或「排除」。
- 数据导入（`数据治理 / 数据导入`）：先「下载模板」取得 CSV 模板，按表头填写后上传并选择数据源，点击「开始导入」；页面展示总行数、成功数、失败数与错误明细，失败行会生成质量问题记录。
- 数据字典与字段口径见 `docs/数据字典.md`。

## 13. 后台管理

- 用户管理：新增用户（登录名、姓名、角色、机构、初始口令）、编辑、启用/停用、重置口令、删除。
- 角色权限：查看 4 个角色的权限点矩阵，勾选后保存即生效（管理员角色不可缩减基础权限）。
- 基础数据：维护品种与地区（编码、名称、品类/层级、启用状态），市场为主数据只读。
- 操作审计：按时间倒序查看登录、预测、训练、导入、处置、配置变更等操作，含操作人、模块、IP、明细。
- 任务调度：查看 5 个内置任务（价格同步、预警扫描、模型重训、日报生成、质量检查）的计划、最近执行结果与下次执行时间；支持手动执行与启停。

## 14. 开放 API

- 入口：菜单「开放 API」。
- 页面提供接口地址、鉴权方式（`Authorization: Bearer <token>`）、请求参数与返回示例，可直接复制。
- 接口清单：`/api/open/v1/prices`、`/forecast`、`/alerts`、`/reports`、`/metrics`。
- 鉴权：两种方式二选一 —— 平台登录 token（`Authorization: Bearer <token>`）或调用方密钥（`X-Api-Key: <client_key>`，在页面「调用方密钥」中创建）。
- 限流：每个调用方按「每分钟调用上限」限流（默认 60 次/分，可在新建/编辑时设置），超限返回 HTTP 429 与错误码 `E4290`，响应头 `Retry-After` 可参考重试。
- 调用统计：选择调用方可查看近 7 天调用量折线、总调用、平均耗时、错误率与 Top 路径；调用流水保留 7 天。
- 密钥管理：新建后明文 `client_key` 与 `secret` 只展示一次，请立即保存；泄漏时用「轮换」生成新密钥，旧密钥立即失效；停用后所有携带该密钥的请求返回 E4010。
- 调用示例：`curl -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:8017/api/open/v1/prices?variety_code=pig&region_code=110000&limit=10"`。

## 15. 数据大屏

- 入口：菜单底部「数据大屏」（顶部菜单点开后独立整屏，无侧边栏），或直接访问 `/screen`；点击右上角「返回主界面」回到工作台。
- 内容：左列品种价格排行与品类占比，中列核心 KPI 四宫格、主力品种走势与区域价格指数，右列未处置预警滚动列表与最新预测摘要；顶部展示数据更新日期与实时时钟。
- 刷新：页面每 30 秒自动刷新一次，也可点「刷新」立即拉取；预警项点击可跳转「预警信息」。
- 用途：会议室大屏或值班台常驻展示，建议 1920×1080 及以上分辨率、浏览器全屏（F11）。

## 16. 通知中心

- 入口：任意业务页面右上角的铃铛图标（带未读数角标）。
- 内容：最近 8 条通知（分类标签、相对时间、未读圆点），分类包括预警、数据、模型、报告、任务、情景、安全、系统；点击「查看全部」可翻看最近 20 条。
- 操作：点击单条通知标记已读并跳转到关联页面；点「全部已读」清空未读数。
- 产生时机：预警扫描命中（全员）、预警确认/关闭（处置人）、数据导入完成、模型训练完成、报告生成、调度任务执行完成。
- 可见范围：个人通知仅本人可见；全员广播（`user_id=0`）所有登录用户可见。

## 17. 模型监测（漂移）

- 入口：菜单「预测分析 / 模型监测」。
- 指标：每个在用模型的 MAPE、近期 MAPE（最近 30 天回测）、误差变化、PSI 与漂移等级（平稳 / 关注 / 漂移）。
- 口径：PSI 比较最近 90 天与之前 180 天的日收益率分布（10 分箱），`<0.1` 平稳、`0.1~0.25` 关注、`>0.25` 漂移；窗口可在页面切换 30/60/90 天。
- 操作：点击表格行查看该品种/地区下 4 类算法的 MAPE 与方向准确率对比；点「重训」可立即重训该组合（需 `model:manage`）。
- 处置建议：出现「漂移」时优先重训并复查特征（节假日、天气、运费、期货指数）是否发生结构性变化。

## 18. 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 启动提示数据库连接失败 | 执行 `npm run infra:up` 检查 MySQL 容器与 `agri_price` 库；确认 13306 端口未被占用 |
| 打开页面提示「数据服务暂不可用」 | 检查后端 8017 是否启动（`npm run dev` 会同时启动前后端） |
| 驾驶舱数据未随导入更新 | 导入成功会主动清理缓存；若仍显示旧值，可等待 30 秒缓存过期或点击「刷新数据」 |
| 登录提示「用户名或密码不正确」 | 确认口令大小写；管理员可在用户管理中重置口令 |
| 开放 API 返回 429 / E4290 | 触发调用方每分钟限流，参考响应头 `Retry-After` 稍后重试，或由管理员调高该调用方的限流值 |
| 通知铃铛一直为 0 | 当前账号没有未读通知；可在「预警信息」处置一条预警或导入数据后再查看 |
| 模型监测全为「漂移」 | 说明近期价格行为与基线窗口差异大，可先重训；若仍为漂移，检查数据源是否变更 |
| 菜单比预期少 | 当前角色无对应权限点，权限矩阵见 `docs/接口契约.md` §0 |
| 图表空白 | 先确认筛选条件下有数据；可点击「刷新数据」重新拉取 |
| 导出 CSV 中文乱码 | 使用 Excel「数据 → 自文本」并选择 UTF-8，或直接双击（文件已带 BOM） |
